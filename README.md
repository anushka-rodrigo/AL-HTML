# HTML Learning Repository for GCE A/L ICT Students (Sri Lanka)

This repository contains **HTML practice files** and exercises designed for GCE Advanced Level (A/L) ICT students in Sri Lanka.  
The purpose of this repository is to provide students with practical examples to learn **HTML structure, tags, and basic web development concepts**.

Students can use this repository to:
- Understand the structure of an HTML document
- Practice creating web pages
- Learn HTML elements, attributes, links, images, and tables
- Explore simple styling and layout

---

## Topics covered

- HTML basics
- HTML forms
- HTML Group Content
- HTML horizontal and vertical frames
